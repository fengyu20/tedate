# Working with other skills

Back to the [README](../README.md).

Use interview skills to sharpen the idea, design skills to shape the experience, and engineering skills to build it. Tedate carries the product goal and accepted decisions into each hand-off, then reviews the result against the original goal. It hands off only when a question needs deeper work; a small question it answers itself, and with no other skill installed it still gives advice and a task you can run.

| When | Hand off to | Tedate takes back |
|---|---|---|
| The idea is vague and needs questioning | an interview skill such as grill-me | the clarified scope, non-goals and what counts as done |
| The idea is clear, but is it worth doing? | a challenge skill such as the-fool, or the heavier office-hours from [gstack](https://github.com/garrytan/gstack); [phuryn/pm-skills](https://github.com/phuryn/pm-skills)' identify-assumptions is one example for mapping assumptions | a decision: validate first, shrink, build or park |
| Public research about needs | a research skill such as customer-research or last30days (read its scripts first: a research skill may send your queries to third-party services). Public research finds leads, it is not the same as talking to users | which findings count as evidence, and how strong |
| The page looks wrong; design or polish | **impeccable** or **ui-ux-pro-max** (optional) | the product goal and accepted decisions go in; the result is checked for real improvement. Without a design skill, Tedate still gives the diagnosis, the direction and a task you can run; if you authorise implementation your own agent does it and Tedate states how far it was verified |
| Code and architecture | any engineering skill you use, for example [mattpocock/skills](https://github.com/mattpocock/skills) or [superpowers](https://github.com/obra/superpowers) | whether the delivery meets the original goal, telling passing tests from a finished task. Optionally point your AGENTS.md at the decision record; that is guidance, not a guarantee every skill follows it |
| Reaching people | your own channel notes; Tedate runs the judging loop (listen, pick one group, test small, read the result) and prepares what to send, but contacts no one | the result of the test |

The hand-offs have not been validated across skill combinations. The other skills named here are optional; Tedate works without them.

The skills named here are independent projects and are not affiliated with Tedate.
